# Inventario de Scripts SQL — INFOREST

> Inventario técnico de scripts Legacy SQL Server. Los scripts estructurales principales (`1. Estructura.sql`, `4. Vistas.sql`, `5. SP.sql`) se leyeron con `utf-16-le`; varios scripts auxiliares del repositorio actual requirieron fallback `latin-1` para inspección.

## Observaciones

- `6. Actualiza.sql` elimina las tablas antiguas `MGUIA` y `DGUIA`, y repuebla el catálogo `TUBIGEO`; es un script de actualización de datos + estructura, no de bootstrap completo.
- `opcionales/Seguridad.sql` crea la base `INFSEGURIDAD`, por lo que debe tratarse como contrato de seguridad/auditoría, no como simple script de datos.
- Se detectó un script adicional no solicitado: `opcionales/Ejecuta Columnas_Ecuador.sql`, que ajusta `MGUIATRANSPORTE`, `DGUIATRANSPORTE` y `DPEDIDO`; conviene incorporarlo en futuros inventarios operativos por país.
