## Estado

Los estándares están definidos como referencia para el desarrollo futuro. Se actualizarán cuando se tome la decisión de arquitectura.

---

## Principios Generales

1. No repetir comportamiento del Legacy sin entenderlo
2. No inventar comportamiento
3. Documentar toda decisión que difiera del Legacy
4. Mantener trazabilidad con el Legacy
5. Aplicar principios SOLID
6. Escribir código testeable desde el inicio
